MODE APPRENTISSAGE DU DÉMON 1 — EXPLICATION SIMPLE

1. Ouvrir la fenêtre de contrôle

Double-clique sur SentinelCore.Demon1.Learning.Controller.exe. La fenêtre s’ouvre, mais elle ne commence pas à surveiller le clavier ou la souris toute seule. Elle montre l’état de l’apprentissage, les dernières mesures, la base et les paramètres.

Exemple : si tu ouvres l’application pour consulter la base, elle ne lance pas la collecte en arrière-plan.

2. Première configuration du propriétaire

Au premier lancement, l’application demande de créer un mot de passe maître d’au moins 12 caractères. Elle ne conserve pas ce mot de passe en clair : elle garde une empreinte calculée à partir de celui-ci, protégée par Windows pour ton compte.

Exemple : tu choisis le mot de passe une seule fois dans la fenêtre de configuration. Tu pourras ensuite le changer depuis le bouton « Changer le mot de passe ».

3. Confirmer le démarrage de l’étude

Pour chaque démarrage de l’apprentissage, choisis Windows Hello ou le mot de passe maître. Windows affiche sa propre vérification configurée sur le PC : cela peut être le visage, l’empreinte digitale ou le PIN Windows Hello. Si cette option n’est pas disponible ou si elle est annulée, rien ne démarre; tu peux utiliser le mot de passe maître à la place.

Après la vérification, une seconde question demande si tu veux vraiment commencer. Il faut répondre oui. Un jeton temporaire, protégé par Windows et utilisable une seule fois, est remis au collecteur pour autoriser ce démarrage.

Exemple : la fenêtre reste ouverte toute la journée. La collecte ne commence qu’après Windows Hello (ou le mot de passe), puis ta confirmation.

4. Ce que le démon apprend

Le démon calcule des mesures résumées sur des périodes configurables : rythme de frappe, durée d’appui et pauses entre les touches, vitesse et variations de la souris, changements de direction et intervalles entre les clics. Il n’enregistre pas les lettres tapées, les mots de passe, le texte du presse-papiers, ni les coordonnées détaillées de la souris.

Exemple : il peut enregistrer « rythme moyen de frappe = valeur X » sans conserver la phrase qui a été écrite.

5. Suivre le travail et consulter la base

La fenêtre d’application actualise l’état et les mesures environ chaque seconde. « Voir la base » affiche les périodes déjà enregistrées et leurs mesures. Les colonnes, décisions, états et noms des mesures sont affichés en français. Les noms techniques internes de la base restent inchangés pour que l’application continue à lire les anciennes données. Les données sont gardées sur cet ordinateur dans le dossier local SentinelCore; les mesures et les profils sont protégés par Windows pour le compte courant.

Exemple : après une période active, tu peux ouvrir la base et voir la date, la qualité et les mesures de clavier/souris, sans retrouver les caractères tapés.

6. Paramètres et arrêt

Le bouton « Paramètres » permet de choisir la durée des périodes de mesure (10 à 60 secondes) et le délai d’arrêt après inactivité (30 à 900 secondes). Ces changements s’appliquent au prochain démarrage. « Arrêter » met fin à la collecte; les périodes déjà sauvegardées restent dans la base. Fermer l’application demande si la collecte doit être arrêtée.

Exemple : avec une inactivité réglée à 90 secondes, le collecteur s’arrête si Windows ne reçoit aucune entrée clavier/souris pendant 90 secondes.

7. Reconnaissance et limites

Ce mode apprend et enregistre un profil de comportement. Il ne compare pas encore la personne présente avec ce profil et ne décide pas si elle est le propriétaire; ce verdict est réservé au futur module de validation. Windows Hello confirme l’identité du compte Windows avec les moyens configurés par Windows; SentinelCore ne lit pas ni n’enregistre le modèle facial ou l’empreinte.

8. Correction de l’erreur montrée

L’ancienne version remplaçait status.json par déplacement d’un fichier temporaire. Sur ton PC, Windows refusait ce remplacement pendant que le fichier était utilisé. Le collecteur écrit maintenant le nouveau statut dans le fichier en autorisant la lecture simultanée; l’interface réessaie la lecture si elle tombe au milieu de l’écriture.

Un test a créé d’abord un status.json existant, lancé l’EXE, vérifié la mise à jour puis arrêté le collecteur : les trois étapes ont réussi sans « Access to the path is denied ».
